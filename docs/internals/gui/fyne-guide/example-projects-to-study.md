# Example projects to study

Do not copy code without checking licenses. Use these as UI/architecture references.

## Official examples

| Project | Source | Why study it |
|---|---|---|
| Fyne demo | `fyne.io/fyne/v2/cmd/fyne_demo` | Canonical widgets, collections, dialogs, bindings, windows, themes. |
| Fyne examples app | `github.com/fyne-io/examples` | Small standalone apps showing real app composition. |
| Clock | `github.com/fyne-io/examples/clock` | Theme-aware custom canvas/layout and timed `fyne.Do` updates. |
| Fractal | `github.com/fyne-io/examples/fractal` | Scientific/computed visualization with `canvas.NewRasterWithPixels`. |
| XKCD | `github.com/fyne-io/examples/xkcd` | HTTP-backed form, image loading, background work, UI update handoff. |
| Bugs / Tictactoe | `github.com/fyne-io/examples/bugs`, `tictactoe` | Custom tappable widgets and simple state/UI split. |
| Calculator | `github.com/fyne-io/calculator` | Focused tool-style UI; useful pattern for module-specific utilities. |
| Life | `github.com/fyne-io/life` | Grid/simulation visualization reference. |
| Solitaire | `github.com/fyne-io/solitaire` | More complex custom interaction/state rendering. |
